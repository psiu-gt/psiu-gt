# psiugt.org

[![Netlify Status](https://api.netlify.com/api/v1/badges/80f9b837-7ec4-4acd-b3fd-511fb49cdf6a/deploy-status)](https://app.netlify.com/projects/psiugt/deploys)

Home page for the Psi Upsilon fraternity's Gamma Tau chapter.

This is a static site generated using the [hugo](https://gohugo.io/) framework.

## Local Development

1. [Install Hugo](https://gohugo.io/installation/)

2. Run the local hugo server with `hugo serve --port 1833` and go over to
   http://localhost:1833

3. Make edits and commit.
